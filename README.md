# 拾词 · Word Garden

一个温馨的单词学习页面，使用原生 HTML、CSS、JavaScript，无需安装依赖或构建。

## 打开方式

直接用浏览器打开 `index.html`，或在项目目录启动本地服务器：

```sh
python3 -m http.server 5173
```

然后访问 http://localhost:5173。

## 功能

- 48 个精选单词，分为自然、情绪、日常、旅行、成长、艺术六个主题。
- 音标、词性、中文释义、英文例句和发音按钮。
- 绿色表示已记住，淡红色表示还没记住；点击状态按钮切换。
- 主题与记忆状态筛选，以及单词、释义、例句搜索。
- 地图式单词区域缩放（25%–150%），导航和工具栏保持原尺寸，支持按钮、滑杆、Ctrl/⌘ + 滚轮以及触控板捏合。
- 缩小时增加列数并逐步隐藏例句、音标和释义；25%–40% 为仅显示单词与记忆颜色的全览，45%–65% 显示词义，70%–85% 加入音标，90% 以上显示完整内容。
- 一键「全览」收起欢迎区域，优先展示尽可能多的单词；「重置」恢复详细学习。单词过多时可正常滚动浏览。
- 任意缩放级别点击单词即可打开完整详情、播放发音或切换记忆状态，关闭后回到原来的浏览位置。适配手机和平板。
- 随机温习最多 10 个未记住的单词，先回忆再查看释义。
- 添加自定义单词，学习状态和缩放设置保存在浏览器 localStorage。

发音通过浏览器 Web Speech API 调用设备上的英语语音，实际音色和可用性取决于浏览器与系统，未内置录音文件。字体使用 Google Fonts，无法联网时自动使用系统字体，其他功能无需外部资源。初次打开时所有单词均为未记住，不预置虚假学习进度。

数据仅存储在当前浏览器中，不会上传或跨设备同步。清除浏览器数据会删除自定义单词和学习进度；直接打开文件与使用本地服务器的存储空间可能不同，建议固定使用一种方式。
