# 拾词 · Word Garden

一个面向美国通用职场和日常生活的英语学习页面。使用原生 HTML、CSS、JavaScript，无需安装依赖或构建。

## 打开方式

保持 `index.html`、`app.js`、`style.css` 与 `data/` 的目录结构，直接用浏览器打开 `index.html`，或在项目目录启动本地服务器：

```sh
python3 -m http.server 5173
```

访问 http://localhost:5173。

## 词库与学习顺序

内置 **10,048 个词条、16 个主题**：职场、租房、购物、餐饮、健康、银行、办事、出行、数字工具、社交、日常、学习、自然、情绪、艺术和通用词汇。

「选择学习范围」包含：

| 范围 | 数量 | 用法 |
| --- | ---: | --- |
| 生活与职场精选 | 134 | 常见美国生活用词、实用短语和沟通句型，附中英例句 |
| 基础常用 | 3,048 | 先学习的常用词，包括原有 48 词及 44 个常见词形、缩写 |
| 进阶表达 | 3,000 | 扩展沟通与阅读表达 |
| 扩展阅读 | 3,866 | 更广泛的阅读和话题词汇 |
| 我的自定义 | 按添加量 | 补充实际生活中遇到的词句 |

层级是本项目按词频和场景设计的学习顺序，不是 CEFR 或官方考试等级。词库不是英语全部词汇，也不能单靠背词保证沟通无障碍；建议从精选场景开始，结合听力、复述和实际对话练习。

## 使用功能

- 每个单词有中文释义、词性和发音按钮；词典条目附音标，短语可整句朗读。
- 绿色表示已记住，淡红色表示还没记住；点击状态按钮切换。
- 主题、学习范围、记忆状态可组合筛选；搜索覆盖整个词库中的英文、释义和例句。
- **一张连续地图**：全部单词共用固定坐标，每行仍为 6 个词，没有分页或词区边界。拖动和滚轮可以连续浏览整张地图；右上角缩略图支持点击、拖动快速定位。
- 筛选只隐藏不匹配的词，保留空位；缩放、窗口调整与记忆状态切换不改变坐标；新增自定义词排在末尾。升级前的原有单词、自定义词和记忆状态保持不变。
- 缩放下限按整张地图大小自动计算，最大 150%；支持按钮、对数滑杆、Ctrl/⌘ + 滚轮和双指捏合。鼠标或单指拖动、普通滚轮平移，聚焦地图后可用方向键移动，Home/End 到达首尾。
- 「全图」显示当前筛选范围的全部位置；「重置」恢复 100% 并定位第一个匹配词。全图概览中，卡片过小时以色块表示，点击可放大到对应单词。
- 搜索定位到匹配词的原坐标，支持跳到上一个／下一个匹配词；筛选不会重新排列单词。
- 常规缩放仅创建视野附近的卡片并复用已有节点；远景改用 Canvas 绘制可见词条的色块。缩略图采用缓存，避免拖动时重复绘制一万个 DOM 卡片。
- 点击单词看完整释义、来源、音标说明以及已收录的中英例句。
- 「温习本范围」在当前主题和学习范围内随机抽取最多 10 个未记住的词，先回忆再看答案。
- 记忆进度、自定义词、缩放、视野与学习范围保存在浏览器 localStorage。

## 发音与数据来源

扩展词典采用 [ECDICT](https://github.com/skywind3000/ECDICT) 的 MIT 许可数据，并补充原创美国生活场景与基础词形。许可证和选词说明见 [data/SOURCES.md](data/SOURCES.md)。

ECDICT 音标以英式为主，详情中已注明。发音通过 Web Speech API 优先调用设备的 `en-US` 语音；若没有美式语音，会回退到可用英语语音。未内置录音文件，实际发音可用性取决于浏览器与系统。没有例句的词典条目明确显示「此词暂未收录例句」。

字体使用 Google Fonts，离线时回退到系统字体；词库已随项目保存，无需联网查询。数据仅保存在当前浏览器，不上传、不跨设备同步；清除浏览器数据会删除自定义词和进度。直接打开文件和使用本地服务器属于不同存储环境，建议固定一种打开方式。

## 维护与验证

词库生成文件为 `data/vocabulary.js`；场景源数据为 `data/scenarios.tsv`，基础词形源数据为 `data/foundation.tsv`。

从 ECDICT 项目取得 `ecdict.csv` 后可重新构建：

```sh
python3 scripts/build-vocabulary.py /path/to/ecdict.csv
node scripts/verify-vocabulary.cjs
node --check app.js
```

浏览器回归检查（环境需已安装 Playwright 和 Google Chrome）：

```sh
node scripts/verify-map.cjs
```

检查包括连续跨越原分页边界、按视野加载与节点复用、全图绘制、搜索定位、固定坐标、旧记录迁移和手机布局。

生成过程不需要网络。`data/vocabulary-meta.json` 保存版本、上游提交、CSV 校验和与分类统计。

固定坐标依赖生成词库顺序，因此已发布的 `data/vocabulary.js` 不应随意重排。未来扩充词库应保持现有条目顺序与 ID，并在迁移中保留已分配的位置。
